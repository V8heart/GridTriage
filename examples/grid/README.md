# 수전점 계측 입력 예시

`pcc_measurement_example.csv`는 **합성 예시 파일**이다. 실제 계통이나 시설에서 잰 값이 아니다. 데이터센터 수전점의 전력품질 계측기·PMU가 내보낼 데이터의 **형식**을 보여 주고, 시연에서 콘솔의 "계통 상태" 칸이 시험 계통(시뮬레이션) 값에서 실측 입력으로 바뀌는 것을 보여 주는 용도다.

## 형식

| 열 | 뜻 |
|---|---|
| `t_s` 또는 `t_epoch` | 시간. `t_s`는 파일 시작부터의 초로, 재생에 맞춰 반복된다. `t_epoch`는 실제 시각으로, 파이프라인 데이터 시각에 맞춘다. |
| `freq_hz` | 측정 주파수 (60 Hz 계통) |
| `voltage_v` | 수전점 전압(선택) |

## 샘플 속도

0.05–2 Hz 진동 주파수를 계산하려면 초당 4샘플 이상이 필요하다. 예시 파일은 초당 30샘플이다. 일반 UPS의 SNMP 값(약 1초 간격)으로는 주파수·전압 표시만 되고, 진동 주파수 칸은 비워진다.

## 예시 신호

- 60 Hz
- 느린 수급 변동
- 0.37 Hz 진동(진폭 최대 8 mHz)
- 측정 잡음

0.37 Hz는 일반적인 계통 간 진동을 흉내 낸 값으로, 재생하는 GPU 세션과는 **무관하다**.
