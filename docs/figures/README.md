# 소개서 그림 (v18 표현력 보강)

다시 만들기:

```bash
.venv-physics/bin/python scripts/make_figures.py
```

모두 300 dpi PNG이고, 수치는 저장소 산출물에서만 가져온다.

| 파일 | 넣을 위치 | 캡션(안) |
|---|---|---|
| `fig1_concept.png` | 2.2 개요 | **그림 1.** GridPulse 개념도. 추가 계측기 없이 GPU 서버 텔레메트리만으로 선별 → 위협 지식 검색 → 근거 기반 판정을 수행하고, 경보 구간은 공개 계통 모델에서 물리 응답을 확인한다. |
| `fig2_architecture.png` | 4.1.1 (코드 대응표를 줄이거나 대체) | **그림 2.** 시스템 아키텍처. 실선은 운영 경로, 점선은 오프라인 적합과 2차 과제다. 임계값과 α, 세션 게이트는 train/cal 분할로만 정한다. |
| `fig3_observability.png` | 4.1.3 | **그림 3.** 같은 SWMA 구간(1초 주기, RTX 4090)의 1초 평균 전력과 순시 전력. 평균 전력은 변조 진폭을 40 W로 지우지만 순시 전력은 418 W를 보존한다. 관측 경계를 측정해 판정 범위를 선언하는 근거다. |
| `fig4_session_gate.png` | 4.4.1 | **그림 4.** 공식 Stage 1의 test 세션 창 판정 예시. 정상 DDP 학습은 후보가 흩어져 경보가 없고, LTMA·SWMA는 후보가 5창 연속(약 90초)이 되면 세션 경보가 난다. 전체 정상 세션 경보율은 표 n(5.2%) 참조. |
| `fig5_ibr_response.png` | 4.4.4 | **그림 5.** WECC 179-bus에서 IBR 비중별 같은 부하 변동(계통 부하의 1.2%, 사각파)에 대한 동기기 회전속도 응답. 주황 띠는 AI 학습 iteration 기본 주파수, 초록 띠는 계통 전기기계 모드 대역이다. IBR 50%에서는 응답이 주파수와 무관하게 커지며(응답 주파수 약 1.9 Hz), 약해진 계통 자체의 진동이 함께 들뜬 결과로 해석한다. |
| `fig6_stage2_accuracy.png` | 4.4.3 | **그림 6.** 위협 지식 검색에 따른 LLM 판정 정확도(실측 107 세그먼트, gemma3:12b). 무작위 문서는 효과가 없고, 관측 시그니처 질의로 지식베이스 1,091건을 검색했을 때만 정확도가 오른다. |

`_swma_power.csv`, `_timeline_data.json`은 그림용 중간 데이터다.
- `_swma_power.csv`: `s-fdb3c79ef8d14b9a` GPU0, 120–132초 구간.
- `_timeline_data.json`: round5b/fold_00 test 세션 창 판정.
